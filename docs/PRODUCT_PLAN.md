# Flexora — план завершения продукта

## Актуальное дополнение: новая регистрация

По новой задаче пользователя реализованы BUSINESS/PERSONAL, отдельные команды, экран подключения по одноразовому коду, ограничение доступа до подключения и новый дизайн форм авторизации. Прежняя отмена этой идеи ниже больше не актуальна. Дизайн дашборда сохранён.

Цель: законченная локальная CRM для одной команды с сохранением данных в PostgreSQL и существующего визуального языка. Не подразумевает SaaS с несколькими изолированными организациями, реальные платежи, SMTP и OAuth без подключённых провайдеров. Эти границы должны быть видны в интерфейсе.

## Критерий готовности

Пользователь проходит цепочку: вход → создание лида → перевод в клиента → создание сделки → задача и исполнитель → смена стадии → выставление и оплата счёта → актуальные показатели и выгрузка. После перезагрузки данные сохраняются. Ошибки видны и не оставляют интерфейс в бесконечной загрузке. Запрещённые действия отклоняются API независимо от UI.
