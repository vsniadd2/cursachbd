# Flexora

Flexora — веб-приложение для управления клиентами и проектами IT-компании. React, TypeScript, Express, Prisma и PostgreSQL. При регистрации «Бизнес» создаёт отдельное рабочее пространство и аккаунт администратора. «Личный аккаунт» открывает `/join-team`, где пользователь присоединяется по коду или ссылке. Одноразовый код действует 7 дней и создаётся в разделе «Команда → Добавить». Доступ внутри команды регулируется ролями. Демонстрационные данные находятся в команде Flexora Demo.

## Запуск

Нужны Node.js 22.12+ (либо совместимая новая версия), npm и запущенный Docker Desktop.

```sh
sh scripts/start.sh
```

Скрипт создаёт `.env` с локальным случайным JWT-секретом, поднимает PostgreSQL и API, применяет миграции, заполняет демонстрационные данные и запускает frontend. Повторный запуск сохраняет данные Docker volume. Первая установка требует доступа к npm и Docker Hub.

- Интерфейс: http://127.0.0.1:5173
- API: http://localhost:3001/api/v1
- Проверка базы: http://localhost:3001/api/v1/health
- Swagger: http://localhost:3001/api/docs (OpenAPI 3.1).
- Администратор демонстрационной команды: `admin@flexora.local` / `admin123`.
- Менеджер: `maya@flexora.local` / `manager123`.
- Сотрудник: `alex@flexora.local` / `employee123`.

Остановка интерфейса: Ctrl+C в его терминале. Остановка API и базы без удаления данных: `docker compose stop`. Не используйте `docker compose down -v`, если нужны сохранённые данные.

## Основной сценарий

1. Войдите администратором и создайте лид: компания, контакты, заметки.
2. Измените его статус на ACTIVE. Запись появится среди клиентов.
3. Нажмите «Проекты» в строке клиента и создайте проект. Задайте сроки, приоритет и плановый бюджет в USD.
4. Откройте карточку проекта. Назначьте руководителя во вкладке «Команда», затем добавьте задачу с исполнителем и сроком во вкладке «Задачи». При завершении задачи прогресс пересчитывается.
5. Создайте счёт с уникальным номером, клиентом, суммой, валютой и сроком. Проект счёта должен принадлежать выбранному клиенту.
6. Переведите счёт в PAID. Дашборд и отчёты покажут оплату в выбранной валюте после открытия/обновления.
7. Выгрузите CSV из таблицы или отчётов. Фильтры таблиц влияют на экспорт. Импорт/экспорт клиентов в JSON находится в интеграциях.

Фильтр клиентов изначально показывает ACTIVE, фильтр лидов — LEAD. Выберите «Все статусы» для полного списка. Проект со связанными задачами или счетами можно перевести в завершённый или отменённый статус. Для удаления сначала уберите связанные записи.

Реестр проектов поддерживает поиск по названию проекта и клиенту, фильтры, сортировку и постраничный просмотр. На доске можно менять статус. Карточка доступна по постоянной ссылке и содержит обзор, задачи, состав команды, счета и журнал изменений проекта. Роль участника отражает его ответственность в проекте. Доступ к операциям определяют права пользователя в рабочем пространстве. Бывшие адреса `/deals` и `/pipeline` открывают список проектов и доску соответственно.

## Аналитика

Выручка учитывает счета PAID в выбранной валюте. Задолженность учитывает счета SENT и OVERDUE. Бюджеты проектов задаются в USD. Суммы счетов отображаются в исходной валюте.

График показывает шесть календарных месяцев по времени оплаты. Для исторических демонстрационных оплат используется время последнего изменения. Доля завершённых проектов считается от всех проектов периода, кроме отменённых. Прогноз использует среднюю оплаченную выручку за последние три календарных месяца, включая текущий, с учётом выбранного фильтра.

## Дополнительные инструменты

- Кампании: сохранение названия, содержания и рабочего статуса; без выдуманных охватов.
- Email: сохраняемые темы и тексты черновиков. COMPLETED означает завершение подготовки, а не отправку письма.
- Автоматизация: активное правило уведомляет своего автора о каждой новой задаче; число запусков хранится в базе. Уведомление и задача создаются одной транзакцией.
- Колокольчик получает уведомления при назначении и смене исполнителя задачи. Уведомления сохраняются в аккаунте, а в открытой вкладке обновляются каждые 5 секунд. Уведомление ведёт к задаче. Звук включается в колокольчике и запоминается в браузере.
- Отзывы: сохранение в базе и личная история. Внешняя отправка отсутствует.
- Команда: роли, права, руководители, отделы, приглашения со сроком действия. Ссылку передают вручную; SMTP отсутствует. Принятие ссылки возможно при регистрации или при входе существующим аккаунтом.
- Google OAuth, SMTP, Slack и платежи не подключены. Google-кнопка отключена; тарифные карточки ведут к обратной связи. Клиентский файл JSON — действующий способ обмена данными.

## Проверки

```sh
cd frontend
npm ci
npm run lint
npm run build
npm test
npm run test:e2e
```

Браузерные тесты ожидают запущенный сайт, демонстрационного администратора и установленный Google Chrome. Проверяют настоящий API, создают записи с уникальными именами и удаляют их после сценария. При аварийном завершении процесса часть тестовых данных может остаться.

```sh
docker compose up -d --build
docker compose exec -T api npm run lint
docker compose exec -T api npm test
```

API-тесты запускают отдельный HTTP-listener на случайном порту и используют текущую локальную базу. Созданные ими бизнес-записи удаляются в `finally`; аудит входов сохраняется. Тесты рассчитаны на локальную демонстрационную базу с исходным администратором, не на реальную рабочую базу.

## Границы локальной версии

Серверное размещение, HTTPS и резервное копирование требуют отдельной настройки. Данные команд разделены на уровне API. Доставка почты, оплата через провайдера и внешние OAuth-интеграции требуют подключения. Refresh-токены отзываются при смене пароля. Уже выданный access-токен действует до истечения своего срока.
